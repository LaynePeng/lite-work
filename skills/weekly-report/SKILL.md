# 周报生成技能

当用户要求写周报时，按以下流程执行：

## 步骤

1. **收集素材**：
   - 用户已提供本周工作内容 → 直接使用；
   - 未提供且工作区是 git 仓库 → 用 git_log 查看本周提交摘要辅助回忆；
   - 仍缺信息 → 用 ask_user 询问关键项（本周完成/下周计划/风险问题）。

2. **确认格式**（用户无特殊要求时使用默认）：
   - 标题：`周报（{起止日期}）`
   - 一、本周工作完成情况（条目式，含进展百分比/状态）
   - 二、下周工作计划
   - 三、问题与风险（无则写"无"）
   - 四、需要的支持（可选）

3. **生成文档**：用 docx_create 生成 Word 文件，文件名 `周报_{起始日期}_{结束日期}.docx`，
   保存到工作区 `.outputs/` 目录；把完整文件路径告诉用户。

## 注意

- 用户提供的事实数据（数字、项目名、人名）必须原样保留；
- 语言风格：简洁书面语，不夸大不缩水；
- 内容较多时先给大纲请用户确认，再生成全文。
