# 单图 / 权要 → 公布站检索式

用户给**一张图**或**一段权利要求**、要求查类似专利时使用。先读图或权要，抽出名称词、摘要特征词和分类号，再调用 `cnipa_search.py`。

这是关键字代理：把图或权要收成公布站名称/摘要检索式，**不是**按附图视觉相似检索，也**不是**按权利要求语义匹配。禁止对用户说「已按图形相似检索」或「已按权利要求语义命中」。

## 必要输入

二选一（可再叠加发明人、申请人、日期等著录字段）：

- **单图**：产品照、结构图、线稿或界面截图一张。用 Read 看图，不要把图交给公布站（站点没有上传入口）。
- **权要**：独立权利要求或保护范围草稿。读文本，不要把整段权要原样填进公布站。

缺图且缺权要时，退回普通著录检索，不要空跑本流程。

口头指定类型是加速器，不是闸门：用户说「用这张图查一下」就直接推断并检索，**不要**先问「这是外观还是实用新型」。

## 单图：必须带 `--type`，禁止 `all`

脚本硬约束：`--derived-from image` 时 `--type` 不能是 `all`（缺省 all 会被拒绝）。必须落到 `design` / `utility_model` / `invention` 之一。

### 类型怎么定

1. **用户说了听用户的**（外观 / 实用新型 / 发明）。不要用看图结果覆盖口头指定。
2. **没说则看图推断**，立刻检索，并加 `--type-inferred`（报告写入推断说明）：

| 图面 | `--type` |
|------|----------|
| 产品照、效果图、包装、造型线稿 | `design` |
| 爆炸图、剖视、装配、零件图、CAD 工程图 | `utility_model` |
| 流程图、系统框图、算法示意 | 主场景不是「图片搜外观/实用」。图明确是方法/系统流程 → `invention`；分不清产品界面还是框图时**问一句**再查 |
| 产品照但功能结构也很突出、两种都像 | 默认 `design` |

3. 推断后必须在对话和报告里让用户看见类型。产品照默认外观时，`--type-inferred` 会写入：「未指定类型，按产品外观检索；若要查结构请说实用新型」。

权要检索**不要**套这套默认：按权利要求主题选 `--type`，可以用 `all`。

## 读图分叉（同一脚本，两套抽词）

定下 `--type` 之后，只走对应口径。不要把外观图抽成「卡扣、铰链」去打实用新型，也不要把结构图抽成「弧面、对称」去打外观。

共用：`--title` 用 2～6 字产品或装置通称，不要品牌、不要整句广告语。词太泛会爆页，太专会 0 条；首次宜 2～4 个摘要词。

### 外观（`design`）

盯整体轮廓、比例、表面装饰，不要拆功能件名称当检索词。

- `--abstract`：造型要点（折叠、镂空、弧面、对称），`and` 连接，运算符前后空格。
- `--class`：洛迦诺（如 `09-03`），**不用 IPC**。无把握可先不填，看命中再收窄。

### 实用新型（`utility_model`）

盯部件、连接、相对位置，不要写「美观、弧线」当检索词。

- `--abstract`：结构/连接词（卡扣、铰链、剖视关系）。
- `--class`：IPC 小类或大组（如 `B65D`、`B25J`），**不用洛迦诺**。

发明（流程图等）写手段与用途，分类号用 IPC。不要把整段权要贴进摘要框。

可用 `derived_query.join_and(["折叠", "杯盖", "密封"])` 检查空格与去重，最终仍以 CLI 字符串为准。

## 执行

```bash
python skills/patent-search/tools/cnipa_search.py \
  --title "杯盖" \
  --abstract "折叠 and 密封" \
  --class 09-03 \
  --type design \
  --derived-from image \
  --type-inferred \
  --derived-note "折叠杯盖，顶部有饮口盖"
```

用户已说「查外观」时去掉 `--type-inferred`。权要同理换 `--derived-from claims`，按权要主题给 `--type`，不要加 `--type-inferred`。

- 必须带 `--derived-from image` 或 `claims`，报告才会标注代理检索。
- 仍走高级查询 `#ti` / `#abs` / `#e51`，分页规则与普通检索相同。
- 对话里先用一两句话说明拟用类型和字段，然后直接检索；用户只要检索式、不要跑网时才停在生成。

## 核对命中

- 用结果里的 IPC / 洛迦诺与拟用分类号对照；对不上的标「分类号未印证」。外观命中应能对上洛迦诺，实用新型对上 IPC。
- 题名或摘要应对上至少一部分特征词；只沾边的不要写成「高度相似」。
- 面向用户必须带上脚本写入报告的免责声明，且**不得**称为查新完成、FTO、侵权筛查或视觉相似检索。
