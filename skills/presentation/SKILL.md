# 演示文稿技能

当用户要求快速产出 PPT 初稿时，按以下流程执行（专业级设计/美化/模板请改用
ppt-master 技能）：

## 步骤

1. **明确需求**：主题、受众、页数预期、场合（汇报/路演/培训）；
   信息不全时用 ask_user 提供选项询问（如：10 页以内精简版 / 20 页详细版）。

2. **先出大纲**：给用户列出每页标题与要点（页1 封面、页2 背景、...、末页 总结），
   用户确认后再生成；已有文档素材时先提炼再列大纲。

3. **生成 PPT**：用 pptx_create，slides 为 JSON 数组：
   - 封面页放 title 参数；
   - 每页用 title + bullets（3~6 条短句，每条不超过 20 字）；
   - 数据页可用 chart_make 生成图表图片，在要点中注明图表文件路径。

4. 交付文件路径，并提示用户：生成的是结构初稿，视觉美化（模板/配色/图片）
   需在 PowerPoint 中继续加工。

## 注意

- 单页要点不超过 6 条，避免大段文字堆砌；
- 汇报型 PPT 结构参考：背景 → 现状 → 问题 → 方案 → 进展 → 计划。
