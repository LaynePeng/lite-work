# 会议技能（多 Agent 群聊共议）

AutoGen GroupChat 范式：N 个 agent **共享议题、轮流发言、看到彼此观点**，
与头脑风暴的区别——头脑风暴是各自独立提案最后汇总（互不可见保证多样性），
会议是实时互相影响、观点碰撞后收敛（适合需要对齐共识的决策）。

## 编排流程

### 第 1 步：确定与会者与议题

选 2-4 个角色（如：架构师 / 后端 / 前端 / 运维），写明议题与目标产出。

### 第 2 步：轮流发言（每轮一个 agent）

按轮次执行（默认 3 轮，可在 spawn 时给各 agent 相同的 mode="meeting"）：

1. spawn 第一位发言者：task 写明议题 + 你的立场，要求给出观点与理由
2. **wait_agents 等它完成**（顺序发言是会议语义）
3. 第二位：task 写明议题 + **前一位的观点摘要** + 「请回应他的观点并给出你的看法」
4. 依次进行，每位都看到之前所有人的发言摘要
5. 第 2 轮起：followup_task 唤醒各 agent——「针对新发言，你是否调整立场？」

### 第 3 步：收敛

最后你（主 Agent）输出：各方的最终立场对比 → 共识点 → 分歧点 → 你的裁决
（裁决是你的职责，不要指望 agent 自己收敛）。

## 与其他模式的区别

- 想要**多样方案**（互不污染）→ 用 brainstorm
- 想要**互相影响、达成一致** → 用本技能
- 想要**对抗审查**（批判挑错）→ 用 agent-debate

## 纪律

- 与会者 2-4 个；超过 4 个会议会发散，应拆议题
- 每轮发言简短（要求 agent 500 字内），长发言轮次会爆上下文
- 轮次 2-3 为宜（配置 agent_meeting_rounds）；僵持时由你裁决并明示理由
- 会议产出物：决议清单 + 各方保留意见（可追溯）
