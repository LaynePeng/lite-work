# 头脑风暴技能（多 Agent 版）

用多智能体协作产出高质量方案：并行独立提案 → 交叉批判 → 综合决策。
不要自己一个人想完所有方案——多样性正是本技能的价值。

## 编排流程

### 第 1 步：构造视角

按问题域选 3-4 个互补视角，在任务描述中明确各自立场与约束，例如：

- 视角 A「激进创新派」：追求最大价值，允许更高风险与改动
- 视角 B「稳健工程派」：最小改动、向后兼容、可回滚
- 视角 C「用户/业务派」：从使用者体验与业务指标出发
- 视角 D「运维/安全派」：可观测性、边界与失败模式（可选）

### 第 2 步：并行提案

对每个视角 spawn_agent（并行执行，不要等待）：

- role=general，task 写明：「你代表【视角 X】就【问题】提出一套完整方案，
  必须符合该视角的立场与约束，输出：方案要点 / 关键取舍 / 风险」
- 视角间禁止交流（各自独立，保证多样性），一次 spawn 完再继续

### 第 3 步：交叉批判

全部提案送达后（wait_agents 或等 [agent:completed] 通知），spawn
一个 role=critic 的批判者：输入三份提案要点，输出「各方案硬伤 +
取长补短的可能性 + 推荐组合」。

### 第 4 步：综合决策

你自己（主 Agent）做最终综合：对比表格 + 推荐方案 + 理由 + 被放弃
方案的保留价值。不要直接转发某个 agent 的结论——综合是你的职责。

## 纪律

- 视角数量 3-4 个为宜；问题过小时建议直接回答，不开多 agent
- close_agent 释放已完成的 agent
- 最终输出必须标注每个结论来自哪个视角（可溯源）
