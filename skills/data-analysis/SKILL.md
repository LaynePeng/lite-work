# 数据分析技能

当用户要求分析数据时，按以下流程执行：

## 步骤

1. **获取数据**：
   - 用户粘贴的数据（CSV/JSON）→ 直接使用；
   - 工作区中的数据文件 → **data_analyze 支持 path 直读**
     （.xlsx/.xls/.csv/.json，含用户上传的 .uploads/ 文件；xlsx 可用
     sheet 参数指定 sheet），无需先 read_file；
   - 没有数据 → 用 ask_user 请用户提供文件或粘贴数据。

2. **探查结构**：用 data_analyze（instructions 含"描述统计"）确认行列数、
   列名、数据类型与缺失情况；向用户简述数据概况。

3. **执行分析**：根据用户问题组合使用：
   - 描述统计（均值/中位数/分布）；
   - 分组聚合（按类别列分组统计）；
   - 排序找 Top N；
   - 相关性分析。

4. **可视化**：关键结论用 chart_make 生成图表（柱状图对比、折线图趋势、
   饼图占比），图表文件与数据结论一起交付。

5. **输出**：
   - 先用文字给出结论（每条结论附数字依据）；
   - 用户需要交付物时用 xlsx_create 导出结果表，或 docx_create 生成分析报告
     （结构：背景 → 数据概况 → 关键发现 → 建议）。

## 注意

- 不编造数据；缺失值处理方式要向用户说明；
- 结论区分"数据显示"与"个人推断"。
